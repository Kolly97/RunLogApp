# RunLog ML-Sidecar — Python-Abhängigkeiten, die beim Packaging in die gebündelte CPython
# installiert werden (scripts/build-sidecar.mjs, je OS auf dessen OS). Ziel: der schwere
# dose_bayes-Pfad (echte Bayes-Dosis-Wirkung) läuft im gepackten Electron-Paket auf mac/win/linux.
#
# Compiler-frei zur LAUFZEIT: pytensor wird über PYTENSOR_FLAGS=cxx= auf den Python-Fallback gezwungen
# (server/ml/sidecar.ts), damit PyMC auch OHNE System-C-Compiler auf sauberen Endnutzer-Rechnern sampelt.
# Für die kleinen N-of-1-Datenmengen ist der Geschwindigkeitsverlust vernachlässigbar.
numpy>=1.26,<2.5     # PFLICHT: trägt den Conjugate-Bayes-Fallback (dose_bayes) + alle numerischen Modelle.
                     # Obergrenze <2.5 wegen numba (transitive Abhängigkeit von shap, siehe unten) — numba
                     # verträgt aktuell kein numpy≥2.5. Bei numba-Update mit anheben.
pymc>=5.16           # Bündelt die echte MCMC-Dosis-Wirkung. Zieht pytensor + scipy transitiv mit.
                     # Fehlt sie zur Laufzeit → engine.py fällt automatisch auf den numpy-Conjugate-Fallback.
#
